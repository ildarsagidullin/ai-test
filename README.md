# Тест уровня владения ИИ

Статический сайт-опрос для GitHub Pages. Ответы отправляются в Google Form и автоматически появляются в связанной приватной Google Таблице.

## Локальный просмотр

```powershell
npm run serve
```

Для безопасной проверки без отправки данных откройте адрес с параметром `?demo=1`.

## Подключение Google Таблицы

1. Откройте [Google Apps Script](https://script.google.com/) и создайте проект.
2. Замените стандартный код содержимым файла `google-apps-script.gs`.
3. Выберите функцию `setupSurveyBackend`, нажмите «Выполнить» и разрешите доступ. Будут созданы Google Form и приватная таблица.
4. Нажмите «Начать развёртывание» → «Новое развёртывание» → «Веб-приложение».
5. Выберите «Выполнять как: я» и «У кого есть доступ: все», затем создайте развёртывание.
6. Скопируйте URL веб-приложения и вставьте его в `submissionEndpoint` в `survey-config.js`.

Публичный доступ относится только к приёму новых ответов. Сама таблица остаётся доступна только владельцу Google-аккаунта.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и загрузите файлы проекта.
2. В настройках репозитория откройте **Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`.
4. После сохранения сайт появится по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.
